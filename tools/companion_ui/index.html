Install or update Package Manager through NEMESIS

Updating or repairing the installer on this drive does not update the installed app. Package Manager cannot install or update itself. These instructions are available offline.

  1. Copy manager/usb.package.manager.zip from your normal package drive to a separate USB drive's root, named usb.package.manager.zip. Keep it compressed.
  2. On that separate drive, create a plain-text file named NEMESIS.data at its root with exactly this content: 
    [nemesis]
version=1.0
type=install
path=usb.package.manager.zip
  3. With the vehicle parked and the head unit fully booted, close Package Manager, safely eject the separate drive from your computer, and insert it in the vehicle. Approve NEMESIS's installation or update prompt. Keep the drive connected and wait for completion.
  4. Open NEMESIS Manager > Packages > Package Manager > Launch, then return to your normal package drive. Keep its disabled root descriptor disabled; do not put this install descriptor on that drive.
