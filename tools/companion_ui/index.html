Quick guide
  1. Select your USB drive.
  2. Use Drive setup to add Package Manager, then Add / update to copy package releases.
  3. Safely eject the drive. In the vehicle, open Package Manager, tap Refresh, and choose Install or Update.

Copying a release to USB does not install it on the head unit. Your existing data folder is kept when updating.
